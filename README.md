# 無心つぶし

気泡シートの粒を、ひたすら潰すだけのゲームです。考えることは何もありません。

遊ぶ: https://keigom.github.io/mushin-tsubushi/

## 遊び方

- 押す、なぞる、キーボードを適当に叩く。どれでも潰れます。
- 1枚は108粒。全部潰すと鐘が鳴り、新しいシートに替わります。
- 金の粒を潰すと、まわりの粒も一緒に潰れます。
- 「自動で潰す」を押すと、勝手に潰れていきます。
- 音は「音 あり／音 なし」で切り替えます。iPhone では消音モードでも鳴ります（iOS 17 以降）。

累計の記録は、遊んだ人それぞれのブラウザに残ります。

## 中身

- `index.html` … ゲーム本体。この1ファイルで動きます。
- `src.html` … 編集用の元ファイル。
- `build.py` … `src.html` から `index.html` を作ります。画面に出す文字だけを拾い、取り寄せるフォントを小さくしています。

粒が潰れる音と鐘の音は、ブラウザの中で計算して作っています。録音した音源は使っていません。

文言や見た目を変えるときは `src.html` を編集して、次を実行します。

    python3 build.py
